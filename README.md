#### Apps

**[Exosuit](https://github.com/OliMoli/pr0phecikdev-releases/releases?q=exosuit&expanded=true)** · Windows · in development
One desktop app to watch and run all your AI coding agents on the subscriptions you already pay for: Claude Code, Codex, Antigravity, Grok Build and Cursor. Sessions, plan limits, missions and reports in one place. No API keys, no access to your login tokens.

**[OmniFetch](https://github.com/OliMoli/pr0phecikdev-releases/releases?q=omnifetch&expanded=true)** · Android + PC · v1.1
One tool, every source. Download video and music from YouTube, TikTok, Instagram and many other sites. Local, no ads, no tracking.
